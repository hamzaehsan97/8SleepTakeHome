# Intent Statement

## Problem Statement

The project is a toy consensus implementation built for a take-home. It is to be reviewed for its architecture first, then its design and code. [desc]

The review judges the project against the take-home brief: a toy consensus algorithm built from scratch with no consensus or replication library, state replicated across a small cluster, and tests that exercise the failure modes that matter. [desc]
